# Taste calibration

The site audit runs the kit's taste rules (`slop-glow`, `card-row`, `uniform-surface`, `intent`) on other people's live sites, and its report often goes to the site's owner. Those rules were tuned on the kit's own designs, so this calibration measures how often each one fires on sites people made by hand. A rule counts as a problem on a live site only while its false-alarm rate here is **5% or less**; otherwise the audit lists it as a note.

```bash
npm run calibrate:taste                          # every page, writes results/<date>.md and .json
npm run calibrate:taste -- --only gov.uk,bbc.co.uk
npm run calibrate:taste -- --offline             # replay the pages cached by the last online run
npm run calibrate:taste -- --write               # also update packages/core/src/export/taste-calibration.json
```

It needs network access to the public sites (except `--offline`) and a Chrome, Edge or Chromium (or `OPEN_DESIGN_BROWSER_PATH`). No model tokens. Each page is loaded at 1440×900 with consent banners hidden, and the same `desktopPasses` the audit uses runs on it.

## What is measured

| Rate | Over | Meaning |
|---|---|---|
| False alarms | `handmade.json` | the share of hand-made sites a rule fired on; this alone decides problem or note |
| Hits | `ai-default.json` | the share of AI-default pages it fired on; reported, to show a rule still catches what it's for |

`template-look` is scored too: a page where two or more different template tells (`slop-glow`, `card-row`, `uniform-surface`) fired. `intent` is a taste rule but not a template tell. A page that fails to load is left out of both counts and listed.

## The sets

- `handmade.json`: about 40 sites built by a team or studio (government, publishers, museums, a design studio, well-known brands and a few deliberately plain sites), each with why it belongs and the date it was added. It includes stripe.com, slack.com and shopify.com, where design-extract's own `indigo-gradient` tell fired ([their calibration](https://github.com/Manavarya09/design-extract/blob/main/bench/results/slop-2026-11-04.md)).
- `ai-default.json`: pages built from AI defaults: pages generated by common site builders and AI app builders without a brand, and the kit's own unguided outputs from `npm run evals`. An entry has a `url`, or a `file` under `pages/` (a page saved with its styles inline). Aim for about 30.

## Cache

An online run saves each page's screenshot and its HTML, with readable stylesheets inlined and scripts removed, to `cache/<site>/` (git-ignored). `--offline` replays those; a cross-origin stylesheet that couldn't be inlined is noted in `cache/<site>/NOTE.txt`, and the replay renders without it.

## When to run it

- When a taste rule changes: run with `--write` and commit `taste-calibration.json` and the results with the change.
- The weekly [extraction benchmark job](../../.github/workflows/extraction-benchmark.yml) runs it and uploads the result.
