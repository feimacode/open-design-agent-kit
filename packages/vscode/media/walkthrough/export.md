# Export images, PDF or PowerPoint

Ask Copilot to export any design:

- "Export this as a PNG under 5 MB."
- "Export this deck as PowerPoint."
- "Give me slides 1 and 3 as images."
- "Print this report to PDF."

Files go to the artifact's `exports/` folder.
