# Pick a design system

Choose one of about 150 brand design systems. Every generation after that uses its colors, typography and components, until you change it. The active one is shown in the status bar.

Have your own brand? Run `/open-design-custom-design-system`, or **Open Design: Import Design System**.

[Read the guide](https://github.com/feimacode/open-design-agent-kit/blob/main/docs/guides/design-systems.md)
