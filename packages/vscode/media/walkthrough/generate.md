# Generate your first design

Open Copilot Chat in **agent** mode and describe what you want:

> Make me a pitch deck for a Series A fintech startup, editorial style.

Copilot picks a recipe from Open Design's catalog, writes the files under `.open-design/`, and opens them in the Artifact Preview.

To run a specific recipe, type `/od-` in the chat input to see the curated commands.

[Read the guide](https://github.com/feimacode/open-design-agent-kit/blob/main/docs/guides/generate-a-design.md)
