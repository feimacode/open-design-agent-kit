# Design system from website

Run `/open-design-design-system-from-website` or select **Open Design: Design System from Website** to import a design system from a website URL.

Paste the website URL and Copilot will analyze its colors, typography, and spacing to create a design system you can use in your designs.

[Read the guide](https://github.com/feimacode/open-design-agent-kit/blob/main/docs/guides/design-systems.md#take-one-from-a-website)
