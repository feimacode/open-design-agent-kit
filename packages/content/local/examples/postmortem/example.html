Exports hung for 47 minutes on a confined Chromium

Reviewed

SEV3Incident INC-0420 (sample)Authors: export maintainers

Image exports from CI runners that picked up a snap-packaged Chromium waited until the 60-second protocol timeout, then failed, for 47 minutes. 312 export jobs failed. A preference order that tried snap Chromium last, and a clearer error, fixed it.

Root cause

  1. Browser discovery returned the first executable it found.
  2. Snap's confinement blocks hidden directories under $HOME and gives the browser a private /tmp.
  3. The page never loaded, so export waited for the full protocol timeout instead of failing fast.

Contributing factors

  • The timeout error didn't say which browser was used.
  • No test covered a browser that launches but can't read the workspace.

What went well

  • The OPEN_DESIGN_BROWSER_PATH override let on-call mitigate without a release.

What went badly

  • Detection relied on a person noticing the failure rate.
