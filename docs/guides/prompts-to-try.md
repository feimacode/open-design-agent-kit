# Prompts to Try

Copy-and-paste prompts that produce real Open Design outputs, grouped by what you want to make. Each one lists the expected output and the guide that goes deeper.

## Posters

```
Make an A3 poster for our hackathon on 4 May, with a QR code to the signup page, dark and moody.
```

A print-ready poster at the size you name (A3 by default for print), with a generated QR code, checked before export.

[Posters and print](posters.md)

## Menus

```
A one-page café menu in A4, two columns, soft paper background, serif headings and sample prices.
```

A menu designed as a print poster, ready to export as PDF or PNG for a print shop.

[Posters and print](posters.md)

## Social posts

```
An Instagram portrait post announcing our v2 launch, with the logo and a call to action.
```

A correctly-sized social image (1080×1350 px by default for Instagram portrait), exported under the platform's file-size limit.

[Social media posts](social-posts.md)

## Decks

```
Turn our Q3 product spec into a five-slide deck, storyline first, with numbers checked.
```

A slide deck generated from a document, built on your active design system and exportable as PowerPoint or PDF.

[Turn a document into a deck](deck-from-a-document.md)

## Cards

```
A 54-card trading deck, poker size, one design per card face, ready to upload to a card printer.
```

Game cards at trading-card size (2.5×3.5 in), one image per face, with bleed for a print house.

[Sell what you make](sell-what-you-make.md)

## Landing pages

```
A landing page for a developer tool: hero, three feature cards, pricing table and sign-up form, Linear-like dark theme.
```

A single-page landing page built from your brief, checked on desktop and mobile, and registered as an artifact.

[Generate a design](generate-a-design.md)
