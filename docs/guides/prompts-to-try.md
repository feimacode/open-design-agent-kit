# Prompts to Try

About 12 copy-and-paste prompts, grouped by who's asking.

## For a Developer

1. **Code Review Assistant**: "Review this code for best practices and security issues."
2. **Bug Finder**: "Find potential bugs in this function: [code snippet]".
3. **Documentation Generator**: "Generate documentation for this function: [function signature]".

## For a Founder

4. **Product Strategy**: "What features should I build next to increase user retention?"
5. **Market Analysis**: "Analyze the competitive landscape for [product type]".
6. **Pitch Deck Outline**: "Create an outline for a pitch deck targeting investors."

## For a Café or Shop Owner

7. **Social Media Post**: "Write an engaging Instagram post about our new summer menu."
8. **Promotional Offer**: "Create a special offer for first-time customers."
9. **Customer Feedback Request**: "Write a request for customer feedback after a purchase."

## For a Card Maker

10. **Design Prompt**: "Create a greeting card design for a birthday celebration."
11. **Material Selection**: "Suggest materials for premium business cards."
12. **Portfolio Description**: "Write a description of my design portfolio for client proposals."

---

Each prompt has a line on what you get, and a link to the guide that goes deeper. Try each prompt in an agent before adding it, and only keep the ones that come out well.
