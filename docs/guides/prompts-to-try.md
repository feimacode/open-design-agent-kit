# Prompts to try

New users often don't know what to ask for. These copy-and-paste prompts have been tried in an agent and are ready to use. Each one includes what you get and a link to the deeper guide.

## For a developer

### Build a landing page for a fintech startup

> Make me a landing page for a Series A fintech startup banking app. Include a hero section, features grid, and CTA.

[Get started](guides/generate-a-design.md) — skills and briefs

### Generate a design system from scratch

> Generate a design system for a productivity app with colors #1a1a2e and #ffffff, typography Inter, and spacing scale 4-8-16.

[Get started](guides/design-systems.md) — specify and switch

### Create a pitch deck

> Make me a pitch deck for a Series A startup. Problem slide, market size, business model, team slide.

[Get started](guides/deck-from-a-document.md) — turn a document into a deck
